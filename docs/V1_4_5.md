# AI-KIT v1.4.5

Mandatory Docker housekeeping now targets zero eligible disposable resources after every build, test and debugging task, with no size/age threshold. The canonical [container contract](../template/ai-kit/CONTAINERS.md#post-test-docker-cleanup) covers containers, anonymous/named disposable volumes, networks, intermediate images and dedicated builder caches, plus separate host RAM and virtual-disk reclamation. [Operational guide](../README.md#maximum-docker-cleanup-and-host-reclamation).

Persistent data, active workloads, unrelated projects and explicitly retained final/recovery images remain protected. Host-wide pruning needs an established inventory and owner maintenance scope. Docker/WSL shutdown and offline compaction require a verified idle window, exact backend disk identity and supported tooling. Updating AI-KIT installs instructions; it starts no cleanup service and does not compact the host from inside the CLI image.

VERSION, CLI, wheel and image target 1.4.5. The release also includes the detailed Windows setup/troubleshooting guide. Existing published tags and registry versions are retained.
