Protect selected models and reasoning effort with general recommendations still enabled. [Usage](../README.md#conditional-exceptions-and-quick-model-preservation), [implementation checks](MODEL_INSTRUCTIONS.md#conditional-model-exceptions), [changelog](../CHANGELOG.md).

## Changes and compatibility

- Optional `model_switching_exceptions` protects astra/fable/k3.1 families or exact model names/IDs. Empty/missing preserves previous behavior; global switching off wins. Full/minimal remains independent.
- `install --protect-model MODEL` appends persistent exceptions without replacing existing entries. Bulk --model-switching-exceptions replaces the list; none alone clears it. Managed helpers and conflict handling update through the existing installer.
- `route --preserve-model MODEL` is invocation-only and writes nothing. --current-model declares user intent for conditional advice and remains distinct from --model recommendation candidates. Neither option proves actual execution or changes a platform model picker.
- Protected or unknown selections suppress model/effort advice, adaptive candidates and routing proposals. Required security/architecture/quality checks remain active.
- Native Codex helpers omit static model/effort overrides while exceptions are configured; custom edits conflict. Existing Aider/native/global settings stay for review. Loaded sessions and inherited host defaults cannot be controlled by this instruction layer.
- Explicit external execution remains scoped and budgeted. Protected benchmark model/effort stay fixed; exception changes cannot silently resume another experiment.
