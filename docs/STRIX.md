# Optional Strix integration

## Decision and ownership

The owner requested Strix alongside the optional security-audit integration. Use the same opt-in, fixed-revision, short-entry-point approach. Strix is an active pentesting runtime; this change integrates its skills and tests installation, without installing that runtime or launching a scan.

- [Manifest](../integrations/strix.json) owns the source identity: usestrix/strix revision f7a32ae62d94872631bc8415073868d02a6ffdaf, nine complete skills and Apache-2.0 LICENSE, 85,970 bytes. Each blob was retrieved from that Git tree and verified before writing. No root NOTICE exists at this revision; original license and skill metadata remain intact.
- Original references live under template/ai-kit/vendor/strix; [.gitattributes](../.gitattributes) preserves their bytes on Windows. [Installer](../scripts/install.py) shares bounded manifest/tree verification with Cloudflare: identity, required files, case-fold aliases and path segments, linked/non-regular paths, one MiB/file and five MiB total limits, sizes, Git blobs and SHA-256. It never fetches or executes upstream code.
- --with-strix / the boolean strix setting select only this payload. Defaults and preset bundles omit it; presets preserve prior explicit selection. Cloudflare and Strix choices are independent. [Registry](../template/ai-kit/SKILLS.md) entries are filtered when absent.
- [Short skill](../template/.agents/skills/strix/SKILL.md) is the only discoverable entry point: Codex allow_implicit_invocation=false; Claude disable-model-invocation=true. All nine upstream skills remain conditional references, including cloud and CI instructions. Runtime setup, target execution, publication and fixes remain governed by the user's scope and Core.
- The installed [contract](../template/ai-kit/STRIX.md) owns mode selection, runtime boundaries and usage. Upstream's floating installer, cloud fallback and model examples do not become defaults. Code targets are writable, so execution uses an isolated reviewed copy; headless scope is selected explicitly to avoid accidentally reviewing only a diff. Local execution can expose code to the chosen model provider.
- Existing baseline/conflict/candidate/backup behavior manages the selected files. Disabling selection retains/reports old files; native-client retirement still needs explicit review. Nothing removes locally adapted source instructions silently.
- [Checker](../scripts/check_kit.py) exempts only successfully manifest-verified external references from authored-language, document-size and active-model example restrictions; UTF-8, skill metadata and Markdown links remain checked. Model examples in these references are not active AI-KIT provider selections.
