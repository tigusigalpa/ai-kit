# AI-KIT v1.4.6

Review-driven release: identical LF bytes across Git, PyPI and Docker, an install-free project CI template, SIGTERM handling as PID 1, hash-pinned release builds with digest-verified uploads, selectable Docker cleanup, robust read-only project facts and doctor, and a landing-page README with user guides. [CHANGELOG](../CHANGELOG.md), [ADR 0016](adr/0016-consistent-distributions-and-safer-defaults.md).

Default installation behavior is unchanged: `docker_cleanup` defaults to `maximum`, presets and extras keep their meaning, and existing project files are preserved. Upgrading an installation made from a CRLF bundle records new source hashes without rewriting files.
