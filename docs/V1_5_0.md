# AI-KIT v1.5.0

Adds a read-only MCP inventory and safer version handling: `aikit mcp report` lists project MCP servers without printing secret values, the installer refuses accidental downgrades unless `--allow-downgrade` is passed, and doctor names the upgrade commands. [CHANGELOG](../CHANGELOG.md), [ADR 0018](adr/0018-mcp-report-and-downgrade-guard.md), [guide](guide/INSTALL.md#review-mcp-servers).

Installation defaults, presets and existing project files are unchanged. The installed [MCP posture](../template/ai-kit/MCP.md) gains a paragraph pointing to the report and upgrades through the normal preserved-conflict path. An older CLI now stops before replacing a newer installation's managed files.
