# AI-KIT v1.4.3

Release date: 2026-10-16. [CHANGELOG](../CHANGELOG.md#v143-2026-10-16) owns history; [PyPI procedure](PYPI.md#release-to-pypi-with-owner-approval) owns publishing instructions.

## Release contents

- Published stable GitHub Releases automatically prepare the Python package: verify the event, run source/behavior checks, build sdist and wheel, check metadata/resources/privacy/licenses/description and smoke-install offline.
- PyPI upload waits for the human owner of environment `pypi`. Agents must not approve or bypass this confirmation. The upload uses OIDC and only the same run's validated artifacts; build jobs receive no OIDC permission.
- Future canonical `vMAJOR.MINOR.PATCH` tags work with the existing tag-only `v*` environment policy. Release tag, runner ref, committed VERSION and canonical repository must agree. Drafts and prereleases skip automatic production preparation.
- Manual dispatch stays available and defaults to build-only validation. Explicit manual uploads require an exact version/tag and production still requires owner approval. TestPyPI remains separate and unconfigured.
- Fifteen event regression tests, a live README PyPI version badge, updated release/recovery instructions and preserved archived changelog text.

VERSION, CLI, package metadata and the local development image advance to 1.4.3. The existing v1.4.2 tag and PyPI files stay unchanged. Docker Hub remains at the separately published 1.4.1 image; this GitHub release does not publish an image there.
