# AI-KIT v1.6.0

English chat defaults, Devin (Windsurf), dedicated JavaScript/Node.js guidance, optional public UUIDs and human Claude GitHub identity. [CHANGELOG](../CHANGELOG.md), [TypeUI setup](../README.md#connect-typeui-to-codex-and-claude), [update commands](../README.md#update-ai-kit).

## Behavior and compatibility

- New and interactive installations default to English chat. Normal upgrades preserve saved languages; explicitly pass --chat-language to change them.
- --agent devin targets current local/desktop .devin/rules; --agent windsurf retains legacy paths. Select both temporarily before explicit legacy retirement; edited rules are preserved as conflicts.
- Package modules receive JavaScript/Node.js guidance; browser profiles need dependency evidence. Existing project-owned module maps remain preserved and can require a reviewed context snapshot/reconciliation.
- --with-uuid is independent of presets/conventions and applies across confirmed stacks. Disabled by default; installation performs no schema or application-code changes. Existing identifiers/contracts survive.
- Claude defaults preserve human author/committer identity and request empty native attribution.commit. Custom settings conflict rather than being overwritten. --with-claude-github adds active human GitHub identity verification before authorized commits; no installation-time login/Git config/commit/push.
- TypeUI MCP setup is documented separately for Codex and Claude Code; installing Web Design does not register or authenticate a server.
