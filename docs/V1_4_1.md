# AI-KIT v1.4.1

Release date: 2026-10-15. [CHANGELOG](../CHANGELOG.md#v141-2026-10-15) owns release history. This patch updates Docker maintenance and distribution privacy on top of [v1.4.0](V1_4_0.md).

## Release contents

- Docker image freshness is part of normal maintenance. When a project has images, installed AGENTS asks the agent to assess changes, update build inputs where needed, rebuild affected images and test their actual behavior. [Canonical policy](../template/ai-kit/CONTAINERS.md#image-freshness), [maintainer procedure](DOCKER.md#change-impact-and-image-refresh).
- Root maintainer `AGENTS.md`, `PROJECT_CONTEXT.md` and `WIKI.md` stay local and untracked. The Docker build context, wheel and source distribution exclude them. Public maintenance starts at [CONTRIBUTING](../CONTRIBUTING.md); clean distributions validate without these optional local files.
- Application templates retain their own three documents. Existing project context, preferences, private dialogue memory, local skill edits and native client configuration keep their normal preservation/conflict rules.
- Regression checks cover root-file exclusion, template inclusion, public links, actual Docker ignore behavior and offline wheel installation. Shared dialogue context and the optional security/design integrations retain their v1.4.0 contracts.

Ignoring an already tracked file does not remove it from Git's index. These root files have been untracked while preserving their local copies. This affects future commits and new packages; it does not erase past Git history or replace previously published images. Root README has no size quota; other instruction budgets remain scoped.

## Use the versioned image

Published image: [tigusigalpa/ai-kit:1.4.1](https://hub.docker.com/r/tigusigalpa/ai-kit/tags?name=1.4.1), for `linux/amd64`. The immutable digest is recorded below after successful upload and independent read-back.

~~~sh
docker pull tigusigalpa/ai-kit:1.4.1
docker run --rm --init --network none --read-only --cap-drop ALL \
  --security-opt no-new-privileges --tmpfs /tmp:rw,nosuid,nodev,size=256m \
  tigusigalpa/ai-kit:1.4.1 --help
~~~

For installation, mount an application at `/workspace` and follow [preview/apply instructions](guide/DOCKER.md). The image uses UID/GID 10001:10001 and entrypoint `aikit`. Keep raw conversations and application data in runtime mounts.
