# Security reporting

This file concerns vulnerabilities in the kit and its installation tools. [Engineering security guidance](template/ai-kit/SECURITY.md) governs generated project work.
Only the current bundle is tested locally; no support window or security response deadline is promised.
Before reporting, check whether the issue affects file preservation, path boundaries, downloaded instructions, or authorization.
Use GitHub private vulnerability reporting on the canonical repository if the owner has enabled it. Its availability is not verified here.
If no private route is available, request a private reporting channel without posting credentials, private code, or exploit details publicly.
Do not invent a contact address or claim active scanning. [GitHub policy guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/add-security-policy).
