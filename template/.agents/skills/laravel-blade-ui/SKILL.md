# Laravel Blade UI

Read `../../../PROJECT_CONTEXT.md` and `../../../ai-kit/settings.json`. Apply when `web_design=true` and the affected interface actually uses Blade.
Follow [Blade implementation](../../../ai-kit/web-design/LARAVEL.md), the project's design system and the existing [Laravel profile](../../../ai-kit/stacks/LARAVEL.md). Verify real routes, server validation and affected interactions as well as the asset build.
