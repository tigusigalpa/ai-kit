# UI review

Read `../../../PROJECT_CONTEXT.md`, `../../../ai-kit/settings.json`, the project design documents, and [UI acceptance](../../../ai-kit/web-design/REVIEW.md). Apply when `web_design=true` and a requested review or a UI change needs visual acceptance.
Use the project's available browser/test tools. Distinguish source review, successful builds, observed browser behavior and unavailable checks. Report concrete issues with a route, viewport, state and reproduction; screenshots support observations but do not prove functionality. Fix issues within the task's existing scope and record unresolved requirements without inventing a passing browser result.
