# Web Design

Read `../../../PROJECT_CONTEXT.md`, `../../../ai-kit/settings.json`, and the [Web Design workflow](../../../ai-kit/WEB-DESIGN.md). Apply when `web_design=true` and the task involves visual design; ordinary backend work does not need this workflow.
Reuse the project's brief, design system, components and stack. Read the Laravel or tool reference only when that route applies. Keep the user's chosen direction authoritative, resolve only material unknowns, and implement within the authorized scope. Review the rendered result when a browser is available and record actual evidence and unavailable checks.
